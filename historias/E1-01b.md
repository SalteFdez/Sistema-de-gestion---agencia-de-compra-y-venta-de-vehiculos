# E1-01b · Cambiar mi PIN

*Refinada con `/story`. Sale de dividir E1-01. Fuente: documento de diseño v2, sección 4.1 ("Cambiar PIN: desde Configuración, pidiendo el PIN actual"; "el mismo componente se usa para crear, confirmar y cambiar el PIN") y sección 10, Etapa 1, ítem 1. Requiere: E1-01.*

## Historia
Como socio, quiero cambiar mi PIN desde Configuración en mi propio dispositivo, poniendo el actual y después el nuevo, para cambiarlo si alguien lo vio sin tener que vincular de nuevo.

## Criterios de aceptación
- [ ] **Cambiar.** Dado que entré con mi PIN, cuando voy a Configuración → "Cambiar PIN", pongo el PIN actual y después el nuevo dos veces igual en el mismo teclado en pantalla, entonces me confirma "PIN cambiado". La próxima vez que se bloquee la app entro con el nuevo, y el viejo ya no sirve.
- [ ] **PIN actual incorrecto.** Dado que estoy cambiando el PIN, cuando pongo mal el PIN actual, entonces los círculos tiemblan y se vacían, y el PIN no cambia. Los fallos cuentan para el mismo bloqueo de 5 intentos / 30 segundos que la pantalla de entrada.
- [ ] **El nuevo no coincide.** Dado que ya puse bien el PIN actual, cuando la confirmación del nuevo no coincide con el primero, entonces me avisa y me pide el nuevo PIN otra vez desde el principio. Si salgo sin terminar, sigue valiendo el PIN anterior.

## Plan
- Una entrada "Configuración" en la pantalla principal provisoria de E1-01, que por ahora tiene solo la opción "Cambiar PIN".
- Un flujo de tres pasos con el mismo teclado numérico de E1-01: PIN actual → PIN nuevo → confirmación.
- El PIN actual se valida contra el hash guardado y comparte el contador de intentos y el bloqueo de E1-01.
- Recién al confirmar, el hash nuevo (con sal nueva) reemplaza al anterior en el dispositivo. Todo es local: no toca Supabase, la sesión ni la tabla `usuarios`.

## Fuera de alcance
- El resto de Configuración (cuentas, categorías, contactos, saldos iniciales): llega con sus historias.
- Recuperar un PIN olvidado: ya lo resuelve E1-01 volviendo a vincular.
- Cambiar la contraseña de Supabase del socio.
- Que un cambio de PIN se propague a otros dispositivos del mismo socio: cada dispositivo tiene su propio PIN.
